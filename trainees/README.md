# 研修生カルテ

研修生ひとりにつき1ファイル。AI社員はここを読んでから教材を作ります。

## ファイル名

`<入職年月>-<ローマ字名>.md` 例：`2026-01-budi-santoso.md`

## 運用ルール

- **新しい研修生が入ったら** `_template.md` をコピーして作成する
- **教材を作るたびに**「学習ログ」に1行追加される（AI社員が自動で追記）
- **人間が書く欄**は「基本情報」「目標」「現場からの申し送り」。ここは上長が更新する
- **書いてはいけない情報**：在留カード番号、パスポート番号、住所、給与、健康情報、家庭事情

## 記入例

`2026-01-budi-santoso.md` が記入例です（実在の人物ではありません）。
運用開始時に削除して構いません。
