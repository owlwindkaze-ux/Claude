# 教材置き場

AI社員が作成した教材が `YYYY-MM/` 配下に保存されます。

```
materials/
  2026-08/
    食事介助の声かけ-語彙.md
    体調変化の語彙.md
    てから-あとで-文法.md
```

## ルール

- **個人名を入れない。** 誰にでも使い回せる形で作る（特定の研修生向けに作った教材も、
  他の研修生に再利用できる）
- ファイル名は「単元名-種別」。日付はディレクトリで表現するのでファイル名に入れない
- フォーマットは `kaigo-japanese-material` スキルの4部構成カードに統一する。
  このディレクトリで独自フォーマットを作らない

## 印刷して使うとき

Markdownのまま渡すと読みにくいので、印刷配布する場合は
「この教材をPDFにして」と依頼すれば `pdf` スキルで整形されます。

## 収録済みの例

`2026-08/食事介助の声かけ-語彙.md` は、記入例カルテ（T-001）の
現場申し送り「『とろみ』『刻み』が伝わらない」に対応して作成した実例です。
動作確認用なので、運用開始時に削除して構いません。
