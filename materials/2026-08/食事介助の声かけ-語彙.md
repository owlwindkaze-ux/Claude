# 食事介助の声かけ｜語彙カード（7語）

- 対象レベル：N4中心（★はN3）
- 単元：2-1 食事介助の声かけ
- 作成のきっかけ：現場から「とろみ」「刻み」が伝わらず食形態を間違えかけたとの申し送り

---

**【N4語彙カード】むせる**

①【意味】
食(た)べ物(もの)や飲(の)み物(もの)が、まちがえて息(いき)の通(とお)り道(みち)に入(はい)って、
急(きゅう)に「ゴホッ」と咳(せき)が出(で)ることです。

②【インドネシア語】
tersedak（直訳：のどに詰(つ)まる／自然な訳：むせる、keselek）

③【接続・コロケーション】
| 形 | 例 |
|---|---|
| 〜がむせる | 利用者さんがむせる |
| むせやすい | むせやすい方 |
| むせています（今の状態） | むせています |

④【介護現場の例文】
- 田中(たなか)さんがむせています。すぐに来(き)てください。
  → Bapak Tanaka tersedak. Tolong segera datang.
- この方(かた)はむせやすいので、ゆっくり食(た)べてもらってください。
  → Beliau mudah tersedak, jadi tolong biarkan makan pelan-pelan.

---

**【N4語彙カード】飲(の)み込(こ)む**

①【意味】
口(くち)の中(なか)の物(もの)を、のどを通(とお)して胃(い)に送(おく)ることです。

②【インドネシア語】
menelan

③【接続・コロケーション】
| 形 | 例 |
|---|---|
| 〜を飲み込む | 食べ物を飲み込む |
| 飲み込みが悪(わる)い | 飲み込みが悪い方 |
| 飲み込めない | 飲み込めません |

④【介護現場の例文】
- 飲(の)み込(こ)んだのを見(み)てから、次(つぎ)の一口(ひとくち)を入(い)れてください。
  → Setelah melihat beliau menelan, baru masukkan suapan berikutnya.
- 今日(きょう)は飲(の)み込(こ)みが悪(わる)いようです。報告(ほうこく)します。
  → Hari ini sepertinya menelannya kurang baik. Saya laporkan.

---

**【N4語彙カード】とろみ**

①【意味】
飲(の)み物(もの)や汁(しる)に粉(こな)を入(い)れて、少(すこ)しどろっとさせることです。
さらさらだとむせる方(かた)のために、飲(の)み込(こ)みやすくします。

②【インドネシア語】
kekentalan（とろみをつける = mengentalkan）
※介護現場では「minuman yang dikentalkan（とろみをつけた飲み物）」の形でよく使う

③【接続・コロケーション】
| 形 | 例 |
|---|---|
| とろみをつける | お茶(ちゃ)にとろみをつける |
| とろみ剤(ざい) | とろみ剤を入れる |
| とろみあり／なし | この方はとろみありです |

④【介護現場の例文】
- この方(かた)のお茶(ちゃ)は、とろみをつけてください。
  → Untuk teh beliau, tolong dikentalkan.
- とろみなしで出(だ)すと、むせてしまいます。
  → Kalau disajikan tanpa dikentalkan, beliau akan tersedak.

---

**【N4語彙カード】刻(きざ)み食(しょく)**

①【意味】
食(た)べ物(もの)を小(ちい)さく切(き)った食事(しょくじ)のことです。
かむ力(ちから)が弱(よわ)い方(かた)のために出(だ)します。

②【インドネシア語】
makanan cincang（直訳：刻んだ食事／自然な訳：makanan yang dipotong halus）

③【接続・コロケーション】
| 形 | 例 |
|---|---|
| 刻み食にする | 刻み食にしてください |
| 食形態(しょくけいたい) | 食形態は刻み食です |
| ふつう食／刻み食／ミキサー食 | 食事の種類の言い方 |

④【介護現場の例文】
- 山田(やまだ)さんは刻(きざ)み食(しょく)です。ふつう食(しょく)ではありません。
  → Bapak Yamada makanannya dicincang. Bukan makanan biasa.
- 食形態(しょくけいたい)がわかりません。確認(かくにん)します。
  → Saya tidak tahu bentuk makanannya. Saya akan konfirmasi.

**【N4語彙カード】一口(ひとくち)**

①【意味】
口(くち)に一回(いっかい)入(い)れる分(ぶん)の量(りょう)です。

②【インドネシア語】
sesuap／satu suapan

③【接続・コロケーション】
| 形 | 例 |
|---|---|
| 一口ずつ | 一口ずつ入れる |
| 一口の量(りょう) | 一口の量を少なくする |
| もう一口 | もう一口いかがですか |

④【介護現場の例文】
- 一口(ひとくち)ずつ、ゆっくり入(い)れてください。
  → Tolong masukkan sesuap demi sesuap, pelan-pelan.
- もう一口(ひとくち)、いかがですか。
  → Mau satu suapan lagi?

**【N4語彙カード】召(め)し上(あ)がる**

①【意味】
「食(た)べる」「飲(の)む」の尊敬語(そんけいご)です。
利用者(りようしゃ)さんやご家族(かぞく)に使(つか)います。

②【インドネシア語】
makan／minum（bentuk hormat：使う相手を敬(うやま)う言い方）

③【接続・コロケーション】
| 普通(ふつう)の言い方 | 尊敬語 |
|---|---|
| 食べますか | 召し上がりますか |
| 食べてください | 召し上がってください |
| 食べました | 召し上がりました |

④【介護現場の例文】
- お食事(しょくじ)、召(め)し上(あ)がりますか。
  → Apakah Bapak/Ibu mau makan?
- 半分(はんぶん)、召(め)し上(あ)がりました。記録(きろく)します。
  → Beliau makan setengah porsi. Saya catat.

**【★N3語彙カード】誤嚥(ごえん)**

①【意味】
食(た)べ物(もの)や飲(の)み物(もの)が、食道(しょくどう)ではなく気管(きかん)（息(いき)の通(とお)り道(みち)）に
入(はい)ってしまうことです。肺炎(はいえん)になることがあるので、とても危険(きけん)です。

②【インドネシア語】
aspirasi（直訳：気管への誤(あやま)った侵入(しんにゅう)／説明訳：makanan atau minuman masuk ke saluran pernapasan）

③【接続・コロケーション】
| 形 | 例 |
|---|---|
| 誤嚥する | 誤嚥しました |
| 誤嚥性肺炎(ごえんせいはいえん) | 誤嚥性肺炎のリスク |
| 誤嚥に気(き)をつける | 誤嚥に気をつけてください |

※「むせる」は症状(しょうじょう)、「誤嚥」は起(お)きたことの名前(なまえ)です。
現場(げんば)では「むせています」と報告(ほうこく)すれば伝(つた)わります。

④【介護現場の例文】
- 誤嚥(ごえん)のリスクがある方(かた)なので、必(かなら)ず座(すわ)って食(た)べてもらいます。
  → Karena beliau berisiko aspirasi, harus makan dalam posisi duduk.
- むせが続(つづ)いています。誤嚥(ごえん)かもしれません。看護師(かんごし)さんを呼(よ)びます。
  → Beliau terus tersedak. Mungkin aspirasi. Saya panggil perawat.

---

## 復習のポイント

- **「わかりません」「確認します」を必ずセットで練習する。**
  食形態がわからないまま提供するのが一番危険です。
- 「むせる」は口頭(こうとう)で言(い)えるまで練習(れんしゅう)する。書けなくてよい。
- 「とろみ」「刻み食」は、実際(じっさい)の食事(しょくじ)を見(み)ながら確認(かくにん)すると定着(ていちゃく)します。
