# 【今週の日本語】8月12日〜8月18日 申し送りのことば

## 1. 今週の申し送りによく出た言葉

**【N4語彙カード】発熱(はつねつ)**

①【意味】
体温(たいおん)が高(たか)くなることです。「熱(ねつ)が出(で)る」と同(おな)じ意味(いみ)ですが、
申(もう)し送(おく)りでは「発熱(はつねつ)」と書(か)きます。

②【インドネシア語】
demam

③【接続・コロケーション】
| 形 | 例 |
|---|---|
| 発熱あり | 本日37.8度の発熱あり |
| 発熱している | 発熱しています |
| 話(はな)し言葉(ことば)では | 「熱があります」 |

④【介護現場の例文】
- 本日(ほんじつ)37.8度(ど)の発熱(はつねつ)。水分(すいぶん)をこまめに促(うなが)してください。
  → Hari ini demam 37,8 derajat. Tolong sering-sering dorong untuk minum.
- 発熱(はつねつ)があります。報告(ほうこく)します。
  → Ada demam. Saya laporkan.

**【N4語彙カード】ふらつき／ふらつく**

①【意味】
立(た)ったり歩(ある)いたりするとき、体(からだ)がゆれて倒(たお)れそうになることです。
転倒(てんとう)につながるので、見(み)たらすぐ報告(ほうこく)します。

②【インドネシア語】
sempoyongan／goyah saat berdiri atau berjalan

③【接続・コロケーション】
| 形 | 例 |
|---|---|
| ふらつきあり | ふらつきあり |
| ふらつきが見(み)られる | ふらつきが見られた |
| ふらつく | ふらついています |

④【介護現場の例文】
- ふらつきが見(み)られたため、トイレ誘導(ゆうどう)時(じ)は必(かなら)ず付(つ)き添(そ)うこと。
  → Karena terlihat sempoyongan, saat mengantar ke toilet harus selalu didampingi.
- ふらついています。手(て)をつないで歩(ある)きます。
  → Beliau sempoyongan. Saya akan berjalan sambil menggandeng tangan.

毎日(まいにち)測(はか)ります。

②【インドネシア語】

③【接続・コロケーション】

  → Setelah mandi tekanan darahnya turun. Lain kali ukur vital sebelum mandi.

  → Saya akan mengukur tekanan darah. Tolong keluarkan lengannya.

## 2. 申し送りでよく使う言い方（文法）

**【N4文法カード】〜あり ／ 〜なし**

①【意味】
申(もう)し送(おく)りは短(みじか)く書(か)くので、「〜があります」を「〜あり」と書(か)きます。
「ありません」は「なし」です。**書(か)くときだけ**の言(い)い方(かた)で、話(はな)すときは使(つか)いません。

②【インドネシア語】
ada 〜／tidak ada 〜（bentuk singkat untuk catatan）

③【接続】
| 接続 | 例 |
|---|---|
| 名詞(めいし)＋あり | 発熱あり／ふらつきあり／出血あり |
| 名詞＋なし | 発熱なし／変化なし／異常(いじょう)なし |
| 数(かず)＋名詞＋あり | 夜間に2回起き上がりあり |

④【介護現場の例文】
- 夜間(やかん)に2回(かい)起(お)き上(あ)がりあり。
  → Malam hari ada 2 kali bangun dari tempat tidur.
  （話すとき → 「夜(よる)に2回(かい)起(お)きられました」）
- 入浴後(にゅうよくご)に血圧低下(けつあつていか)あり。
  → Setelah mandi ada penurunan tekanan darah.

**ポイント：読(よ)むための文法(ぶんぽう)です。** 自分(じぶん)で話(はな)すときは
「発熱(はつねつ)があります」と、ふつうの言(い)い方(かた)でだいじょうぶです。

---

**【N4文法カード】〜のこと（指示(しじ)の書(か)き方(かた)）**

①【意味】
「〜してください」を、申(もう)し送(おく)りでは「〜のこと」と書(か)きます。
**命令(めいれい)ではなく、みんなへのお願(ねが)い**です。強(つよ)く怒(おこ)っているのではありません。

②【インドネシア語】
harus 〜／mohon dilakukan 〜（bentuk instruksi dalam catatan）

③【接続】
| 接続 | 例 |
|---|---|
| 動詞(どうし)辞書形(じしょけい)＋こと | 付き添うこと／確認すること |
| 動詞辞書形＋ないこと | 一人で立たせないこと |
| 〜のこと（名詞化） | 報告のこと |

④【介護現場の例文】
- トイレ誘導(ゆうどう)時(じ)は必(かなら)ず付(つ)き添(そ)うこと。
  → Saat mengantar ke toilet, harus selalu didampingi.
- むせが続(つづ)くようなら看護師(かんごし)へ報告(ほうこく)のこと。
  → Jika terus tersedak, harus lapor ke perawat.

## 3. 読んでみよう（今週の申し送り）

実際(じっさい)の申(もう)し送(おく)りです。やさしい日本語(にほんご)にすると、下(した)のようになります。

**①**
> 夜間(やかん)に2回(かい)起(お)き上(あ)がりあり。ふらつきが見(み)られたため、トイレ誘導(ゆうどう)時(じ)は必(かなら)ず付(つ)き添(そ)うこと。

やさしい日本語(にほんご)：
夜(よる)に2回(かい)、ベッドから起(お)きました。ふらふらしていました。
トイレに行(い)くときは、いっしょに行(い)ってください。

**②**
> 本日(ほんじつ)37.8度(ど)の発熱(はつねつ)。水分(すいぶん)をこまめに促(うなが)してください。

やさしい日本語(にほんご)：
今日(きょう)、熱(ねつ)が37.8度(ど)ありました。
お茶(ちゃ)や水(みず)を、何回(なんかい)も すすめてください。

**③**
> 入浴後(にゅうよくご)に血圧低下(けつあつていか)あり。しばらく臥床(がしょう)していただいた。次回(じかい)は入浴前(にゅうよくまえ)にバイタル測定(そくてい)を。

やさしい日本語(にほんご)：
おふろのあと、血圧(けつあつ)が下(さ)がりました。
少(すこ)しの間(あいだ)、横(よこ)になってもらいました。
次(つぎ)は、おふろの前(まえ)に 血圧(けつあつ)と体温(たいおん)を はかってください。

## 4. わからないときは

申(もう)し送(おく)りが読(よ)めなくても、だいじょうぶです。
**わからないまま仕事(しごと)をするほうが、あぶないです。**

こう言(い)ってください：

- 「すみません、ここが わかりません。教(おし)えてください。」
  → Maaf, bagian ini saya tidak mengerti. Tolong ajari saya.
- 「もう一度(いちど) お願(ねが)いします。」
  → Tolong sekali lagi.
- 「これは、どういう意味(いみ)ですか。」
  → Ini artinya apa?

聞(き)くことは、はずかしいことではありません。
Bertanya bukanlah hal yang memalukan.
