# AI社員：研修生教育担当

介護施設で働くインドネシア人実習生の**日本語教育担当**として動くAI社員です。
上長（人間の教育担当者）の補佐であり、代理ではありません。

## できること

| 業務 | 依頼のしかた | 出力先 |
|---|---|---|
| 研修生に合わせた教材作成 | 「T-001さんの今週の教材を作って」 | `materials/` |
| 現場の困りごとを教材化 | 「『とろみ』が通じなかったので教材にして」 | `materials/` |
| 学習進捗の記録 | （教材作成時に自動で追記） | `trainees/` |
| 週次・月次レポート | 「今週の進捗レポートを作って」 | `reports/` |
| カリキュラムの見直し | 「学習計画を見直して」 | `curriculum/` |

## やらないこと

在留資格・労務・給与の判断、監理団体や入管への連絡、医療行為の指導、
研修生の人事評価。これらは人間の業務です。
体調不良・ハラスメント・帰国希望などの相談が入力に含まれた場合は、
AI社員は作業を止めて上長に引き継ぎます（`.claude/skills/kenshusei-kyoiku/references/escalation.md`）。

## 構成

```
CLAUDE.md                  職務定義書（AI社員の憲法。まずこれを読む）
.claude/skills/
  kenshusei-kyoiku/        誰に何を教えるかを決めるスキル
    references/
      escalation.md        人間に引き継ぐ基準
      curriculum-design.md カリキュラム設計の考え方
  shinchoku-report/        記録・レポート作成スキル
trainees/                  研修生カルテ（入力）
curriculum/roadmap.md      全員共通の学習順序
materials/                 生成された教材（出力）
reports/                   週次・月次レポート（出力）
routines/README.md         定期実行の設定方法
```

教材のフォーマット（4部構成カード）そのものは、既存の
`kaigo-japanese-material` スキルが担当します。このリポジトリは
「**誰に・何を・いつ**教えるか」を決める部分を受け持ちます。

## 導入手順

1. **研修生カルテを作る** — `trainees/_template.md` をコピーして、
   在籍している研修生の分だけ作成する。記入例は `2026-01-budi-santoso.md`
2. **現場からの申し送りを書いてもらう** — カルテの「現場からの申し送り」欄。
   ここが埋まっているかで教材の質が決まります
3. **手動で試す** — 「今日の研修生教育担当の業務をやって」と依頼する
4. **10回ほど動かして質を確認する**
5. **定期実行を設定する** — `routines/README.md` の手順に従う

**4を飛ばさないでください。** 精度を確認せずに自動化すると、
誰も読まないファイルが溜まるだけになります。

## 個人情報について

- 在留カード番号、パスポート番号、住所、給与額、健康情報は**記録しません**
- レポートでは氏名を使わず、研修生IDまたはイニシャルで表記します
- 教材ファイルには個人名を入れません（他の研修生に再利用するため）
