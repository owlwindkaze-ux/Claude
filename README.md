# AI社員：研修生教育担当

介護システムから出した**申し送り**を、インドネシア人実習生向けの**日本語教材**にして、
**Gmailで送る**ところまでを担当するAI社員です。

## いちばんやりたいこと（主業務）

```
介護システムのExcel
   ↓  申し送り欄だけ取り出す（利用者名・職員名は自動でマスク）
   ↓  出てきた語彙・文法を教材に整理する
   ↓  送信用ファイルを作る
Gmailの下書き  →  上長が確認  →  送信
```

### やり方

**1. Excelを `work/` に置く**（介護システムから落としたファイルをそのまま）

**2. こう言うだけ**

```
work/介護記録_202608.xlsx から今週の申し送りを教材にして、Gmailの下書きを作って
```

これで、抽出 → 教材化 → 送信用ファイル作成 → Gmail下書き まで進みます。

**3. 下書きを確認して、自分で送信ボタンを押す**

AI社員は**下書きまでしか作りません**。送信は必ず人間が行います。
実習生に届くものなので、中身を見ずに自動送信しない設計にしています。

### 手動で試すとき

```bash
# どんな列があるか見る
python3 tools/extract_moushiokuri.py work/介護記録_202608.xlsx --list

# 申し送りだけ取り出す（8/12以降）
python3 tools/extract_moushiokuri.py work/介護記録_202608.xlsx --since 2026-08-12
```

## そのほかにできること

| 業務 | 依頼のしかた | 出力先 |
|---|---|---|
| 研修生に合わせた教材作成 | 「T-001さんの今週の教材を作って」 | `materials/` |
| 現場の困りごとを教材化 | 「『とろみ』が通じなかったので教材にして」 | `materials/` |
| 学習進捗の記録 | （教材作成時に自動で追記） | `trainees/` |
| 週次・月次レポート | 「今週の進捗レポートを作って」 | `reports/` |
| カリキュラムの見直し | 「学習計画を見直して」 | `curriculum/` |

## やらないこと

- **Gmailの送信**（下書きまで。送信ボタンは人間）
- 在留資格・労務・給与の判断、監理団体や入管への連絡
- 医療行為・介護技術の指導（日本語の面だけを扱う）
- 研修生の人事評価

体調不良・ハラスメント・帰国希望などの相談が入力に含まれた場合は、
AI社員は作業を止めて上長に引き継ぎます。

## 個人情報の守り方

申し送りには利用者の健康情報が入っています。ここが一番大事な部分です。

| 場所 | 中身 | 扱い |
|---|---|---|
| `work/` | Excelと抽出した申し送り | **Gitに登録されません。実習生に送りません** |
| `materials/` | 送信用の教材 | 個人名なし。マスク済み。ここだけを送ります |

- 利用者名は「利用者A」、職員名は「職員A」に自動で置き換わります
- 置き換え漏れの可能性があると、抽出時に `⚠` で警告が出ます
- 教材にするのは「発熱」という**言葉**であって、「誰が発熱したか」ではありません
- 送信先は `config/送信先.md` に書いたアドレスだけ。全員宛はBCCです

## ファイルの置き場所

```
CLAUDE.md                  AI社員の職務定義（何をして、何をしないか）
tools/
  extract_moushiokuri.py   Excelから申し送りを取り出すプログラム
work/                      Excelと抽出結果（Git非登録・送信禁止）
materials/                 送信用の教材（ここを送る）
config/送信先.md            Gmailの宛先（人間が管理）
trainees/                  研修生カルテ
curriculum/roadmap.md      学習の順序
reports/                   週次・月次レポート
.claude/skills/            AI社員の手順書
  moushiokuri-kyozai/      申し送り → 教材 → Gmail（主業務）
  kenshusei-kyoiku/        誰に何を教えるかの判断
  shinchoku-report/        記録とレポート
```

## はじめる前に

1. `config/送信先.md` に実習生のメールアドレスを書く
2. Excelを `work/` に置いて、`--list` で列が正しく取れるか確認する
3. 教材を数回作って中身を確認する（**自動送信の設定はまだしない**）
4. 内容に納得できたら、定期実行を検討する（`routines/README.md`）
