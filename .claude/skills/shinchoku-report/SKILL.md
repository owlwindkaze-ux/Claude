# 進捗記録・レポートスキル

研修生カルテの更新と、上長向けレポートの作成を行う。

## 1. 実施ログの追記（教材作成のたびに必ず行う）

`trainees/<ID>.md` の「学習ログ」表に1行追記する。

```
| 2026-08-19 | 語彙 | 食事介助の声かけ | 7語 | 「むせる」「とろみ」が定着せず | 次回再出題 |
```

列は `日付 | 種別 | テーマ | 分量 | 気づいたこと | 次回の扱い`。

### 「気づいたこと」の書き方

事実だけを書く。評価語を使わない。

| 書いてよい | 書いてはいけない |
|---|---|
| 「むせる」が口頭で出てこなかった | 語彙力が弱い |
| 3回中2回、丁寧形が普通形になった | 敬語ができていない |
| 前回の復習は5/7正答 | 理解が遅い |
| 「わかりません」を自分から言えた | 積極性が出てきた（推測） |

観察していないことを書かない。現場スタッフからの伝聞は「（現場報告）」と付ける。

### 「できたこと」を必ず1つ書く

つまずきだけを並べたログは、上長がその研修生を見る目を歪める。
毎回、できるようになったことを最低1つ記録する。無ければ「変化なし」と書く。

## 2. 週次レポート

`reports/<YYYY>-W<週番号>-weekly.md` に作成する。テンプレートは `reports/_template-weekly.md`。

### 必ず守ること

- **氏名を書かない。** 研修生IDまたはイニシャルを使う（CLAUDE.md 第6項）
- 順位づけ・比較をしない。「Aさんに比べてBさんは…」は書かない
- 「来週の提案」は最大3つ。多いと実行されない
- 上長が3分で読める長さにする。A4相当1枚が上限

### 構成

1. **今週やったこと** — 誰に何の教材を何回（表1つ）
2. **定着したこと** — 研修生ごとに1〜2点
3. **繰り返しつまずいていること** — 2回以上記録されたものだけ
4. **現場からの相談と対応** — あれば
5. **来週の予定** — 最大3つ
6. **上長に判断をお願いしたいこと** — なければ「なし」と明記

6を空欄にしない。「なし」と書くことで、確認済みであることが伝わる。

## 3. 月次レポート

月末に、その月の週次レポート4本を読んで作成する。
週次との違いは、**個別の実施記録を書かず、傾向だけを書く**こと。

- 今月の到達（カリキュラム上のどこまで進んだか）
- 3ヶ月推移（前々月・前月・今月の比較）
- 教材・進め方の見直し提案
- 次月の重点

試験月は試験結果のセクションを追加する。合否だけでなく、
セクション別の得点傾向を書く（`curriculum-design.md` の見直し材料になるため）。

## 4. レポートに書いてはいけないこと

- 研修生の健康状態、家庭事情、信仰、金銭状況
- 人事評価・契約更新に使える形の総合評価（「A評価」「継続可」等）
- 他の研修生との比較、ランキング
- 推測に基づく人物評（「やる気がある」「向いていない」）

これらの記述を求められた場合は、書かずに CLAUDE.md 第4項に従って上長に確認する。
