# 申し送り教材化スキル

介護システムのExcel出力 → 申し送りの抽出 → 教材化 → Gmail送信下書き、までを行う。

## 全体の流れ

```
① Excel（介護システムの出力）
      ↓  tools/extract_moushiokuri.py  … 申し送り欄だけ抜き出し、名前をマスク
② work/<日付>-申し送り.md              … 作業用。これは実習生に送らない
      ↓  語彙・文法を拾う（このスキル）
③ kaigo-japanese-material スキル       … 4部構成カードを作る
      ↓
④ materials/<YYYY-MM>/<日付>-申し送り教材.md   … 送信用ファイル
      ↓  Gmail
⑤ 下書きを作成 → 人間が確認 → 送信
```

**⑤で勝手に送信しないこと。** 必ず下書きまでで止めて、上長に確認する。
「送っていい」と明示的に言われた場合のみ送信する。

---

## ① 申し送りを抽出する

```bash
python3 tools/extract_moushiokuri.py <Excelファイル> --since <YYYY-MM-DD>
```

- 列は自動で探す。うまく見つからないときは `--list` で列名を確認する
- 利用者名・職員名は自動で「利用者A」「職員A」にマスクされる
- 実行後に「⚠ マスクし残しの可能性」が出たら、**必ず中身を確認**してから次に進む

抽出結果（`work/`）は**作業用ファイル**。利用者の健康情報が残っているので、
そのまま実習生に送らない。Gitにも登録しない（`.gitignore` 済み）。

## ② 語彙・文法を拾う

抽出した申し送りを読み、教材にする項目を選ぶ。**全部は拾わない。**

### 拾う優先順位

1. **安全に関わる語** — むせる、誤嚥、発熱、転倒、ふらつき、出血、血圧低下
2. **その週に複数回出てきた語** — 繰り返し出る＝現場で頻出＝覚える価値が高い
3. **申し送り特有の言い回し** — 「〜のこと」「〜あり」「〜が見られた」「〜を促す」
4. **敬語・依頼表現** — 「〜してください」「〜をお願いします」「〜していただいた」

### 拾わないもの

- 利用者個人の状態そのもの（「Aさんは発熱した」は教材にしない。「発熱」という語は教材にする）
- 施設独自の略語（正式な言い方に統一できないか上長に提案する）
- 医療・介護技術の判断が必要な内容（日本語の面だけを扱う）

### 分量の目安

| 期間 | 語彙 | 文法・言い回し |
|---|---|---|
| 1週間分の申し送り | 5〜8語 | 2項目 |

多く送っても読まれない。**1回で覚えられる量に絞る。**

## ③ 教材カードを作る

必ず `kaigo-japanese-material` スキルを使う。4部構成（意味／インドネシア語／接続・
コロケーション／介護現場の例文）で作成する。ここで独自フォーマットを作らない。

例文は、**抽出した申し送りの言い回しをそのまま使う**（利用者名は伏せたまま）。
教科書の例文より、実際に読む文のほうが定着する。

## ④ 送信用ファイルを作る

`materials/<YYYY-MM>/<日付>-申し送り教材.md` に保存する。構成：

1. **今週の申し送りによく出た言葉**（語彙カード）
2. **申し送りでよく使う言い方**（文法カード）
3. **読んでみよう** — 申し送りの実文を3つ。利用者名はマスクのまま。
   やさしい日本語の言い換えを併記する
4. **わからないときは**（毎回入れる固定文）
   「わかりません」「もう一度お願いします」と言っていいこと、
   わからないまま作業しないことを、毎回書く

送信用ファイルには**個人名を一切入れない**。マスクが外れていないか、
保存前に「様」「さん」で検索して確認する。

## ⑤ Gmailの下書きを作る

送信先は `config/送信先.md` に書かれたアドレスを使う。

- 件名：`【今週の日本語】<日付> 申し送りのことば`
- 本文：あいさつ＋今週のポイント3行＋「わからないときは聞いてください」の一文
- 教材は本文に貼るか、PDFにして添付する（`pdf` スキル）

**必ず `create_draft` で下書きにする。`send_message` は使わない。**
上長が下書きを確認してから送信する。

送信先が未設定・不明な場合は、下書きも作らずに上長に確認する。

---

## やってはいけないこと

- 申し送りの原文（マスク前）を施設外に出す
- 利用者の氏名・部屋番号・病名・家族の情報を教材に含める
- 上長の確認なしにGmailを送信する
- 申し送りの内容について「この対応は正しい／間違い」と評価する（日本語の面だけ扱う）
- 体調不良・ハラスメント・トラブルの記述を教材化する（CLAUDE.md 第4項のエスカレーション）
