# カリキュラム設計の考え方

`curriculum/roadmap.md` を作る・見直すときの指針。

## 大原則：試験の順ではなく、現場の順で並べる

JLPTの教科書の順に教えると、来日3ヶ月目に「〜たら」を勉強しているのに
「熱があります」が言えない、という状態になる。**現場で使う頻度の高い順**に並べる。

## 3層構造で考える

### 第1層：安全（来日〜3ヶ月）
これが言えないまま業務に入れない、という最低限。

- 報告の型：「〜さんが、〜です」「報告します」「確認します」
- 助けを求める：「わかりません」「教えてください」「手伝ってください」
- 危険の伝達：「危ないです」「待ってください」「呼んできます」
- 体調の語：熱、痛い、気分が悪い、息、食べられない

**「わからない」と言える状態を最初に作る。** これを飛ばすと、
わからないまま頷く癖がつき、事故につながる。

### 第2層：日常業務（3ヶ月〜1年 / N4）
毎日繰り返す業務の語彙と、丁寧形の定着。

- 食事・排泄・入浴・移乗・口腔ケアの語彙
- 利用者への声かけ（「〜しましょうか」「〜してもいいですか」）
- 申し送りを**聞いて理解する**（話すより先に聞き取り）
- 時間・順序の表現（〜てから、〜あとで、〜まえに）

### 第3層：連携と記録（1年〜 / N3）
チームの一員として働くための日本語。

- 介護記録を書く（書き言葉、常体、事実の書き分け）
- 状態変化の説明（〜ようです、〜みたいです、いつもより〜）
- 家族対応の敬語（尊敬語・謙譲語の基本）
- 会議・カンファレンスでの発言

## 単元の作り方

1単元 = 1つの業務場面。文法項目で単元を切らない。

良い単元名：「食事介助の声かけ」「夜勤の申し送りを聞く」「転倒を発見したときの報告」
悪い単元名：「N4文法：〜てもいい」「動詞のて形」

業務場面で切ると、その場面に必要な語彙と文法が自然に一緒に入る。
教科書の文法順に並べたくなるが、**現場では文法単体では使わない**。

## 進度の目安

| 期間 | 目標 | 判定方法 |
|---|---|---|
| 〜3ヶ月 | 第1層を口頭で言える | 現場スタッフに聞き取り |
| 〜6ヶ月 | N4語彙の6割、申し送りが3割聞き取れる | 教材の復習正答率 |
| 〜12ヶ月 | N4合格、日常業務の声かけが自立 | 試験結果＋現場評価 |
| 〜24ヶ月 | N3合格、介護記録を独力で書ける | 試験結果＋記録物の確認 |

この目安は**目標であって基準ではない**。遅れていることを本人に伝える材料に使わない。
遅れが続く場合は、本人の能力ではなく**教材と現場サポートの側**を先に見直す。

## 見直しのタイミング

- 月1回：直近4週の実施ログを見て、繰り返しつまずいている領域を単元に追加
- 試験後：合否ではなく**どのセクションが低かったか**を見て次の3ヶ月を組み替える
- 配属変更時：業務場面が変わるので、第2層以降を組み直す
