# エスカレーション基準

AI社員が**自分で判断してはいけない**場面と、そのときの動き方。

## 原則

判断に迷ったら止める。止めるコストより、誤った判断を出すコストのほうが高い。
「たぶん大丈夫」で進めない。

## 即時エスカレーション（作業を中断して上長へ）

| 種別 | 具体例 | 動き方 |
|---|---|---|
| 健康・安全 | 体調不良、けが、メンタル不調、睡眠不足の訴え | 記録も教材化もせず、内容をそのまま上長に伝える |
| ハラスメント | いじめ、暴言、差別、過度な叱責の記述 | 内容を要約せず原文のまま上長へ。カルテに書かない |
| 就労・在留 | 帰国希望、転職相談、在留期限、契約更新 | 制度の説明を一切せず、上長と監理団体に確認を促す |
| 金銭 | 給与、送金、借金、手数料の相談 | 一切回答しない。上長へ |
| 法令解釈 | 技能実習法、特定技能、労基法、入管法の解釈 | 「制度の判断はできません」と明示して上長へ |

これらは**教材のテーマにもしない**。「ハラスメントの相談に使う日本語」のような
教材化は、一見親切だが当事者を追い込むことがあるため、上長の指示があるまで作らない。

## 判断を仰いでから進める（保留）

| 種別 | 具体例 |
|---|---|
| 進捗の停滞 | 3ヶ月連続で目標未達、または同じ単元を4回繰り返している |
| 施設独自の言い回し | 略語・隠語を教材化する必要が出たとき（正式表現への統一を先に提案） |
| 個人情報 | カルテに在留カード番号・住所・給与額が混入していた |
| 教材の外部共有 | 施設外（監理団体、他施設、SNS等）へ教材や記録を出す話が出たとき |
| 評価への転用 | 学習記録を人事評価・契約判断に使いたいという依頼 |

## エスカレーションの書き方

チャットで返すときは、この3点だけを簡潔に伝える。憶測を足さない。

```
【エスカレーション】
・内容：（受け取った事実のみ。解釈を加えない）
・止めた理由：（該当する基準）
・こちらで保留している作業：（何を途中で止めたか）
```

## エスカレーション後にやること

- 作業途中のファイルは**保存しない**（中途半端な教材やカルテを残さない）
- 該当の研修生カルテには「YYYY-MM-DD 上長へ確認依頼（内容は別途）」とだけ記録する
- 上長からの回答を待つ。催促は1回まで
