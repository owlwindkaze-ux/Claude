# 研修生教育担当スキル

介護施設のインドネシア人実習生に対して、**誰に・何を・いつ教えるか**を決めるスキル。
教材のフォーマット作成そのものは `kaigo-japanese-material` スキルの担当なので、
このスキルでは「テーマ選定」と「進め方の判断」を行い、実作成は必ずそちらに渡す。

## 使う順番

1. 対象の研修生カルテ `trainees/<ID>.md` を読む
2. カリキュラム `curriculum/roadmap.md` で現在の到達段階を確認する
3. 下の「テーマ選定ロジック」でテーマを決める
4. `kaigo-japanese-material` スキルで教材を作成する
5. `materials/<YYYY-MM>/<テーマ>.md` に保存する
6. カルテに実施ログを1行追記する（`shinchoku-report` スキルの形式に従う）

研修生が指定されていない場合は、`trainees/` 配下の全カルテを見て、
**最も長く教材が出ていない研修生**を対象にする。

## テーマ選定ロジック

上から順に判定し、最初に該当したものを今回のテーマにする。

### 優先度1：現場からの困りごと（即応）
依頼文に「通じなかった」「伝わらない」「間違えた」という具体的な場面が含まれる場合、
その場面の語彙・文法を最優先でテーマにする。ロードマップの順番より優先する。

### 優先度2：安全に直結する語彙の未習得
カルテの「未習得」欄に以下のカテゴリが残っている場合、それを次のテーマにする。

| カテゴリ | 例 |
|---|---|
| 急変・事故 | 誤嚥、転倒、出血、意識、呼吸、救急 |
| 体調変化 | 発熱、痛み、めまい、吐き気、しびれ |
| 報告・連絡 | 報告します、確認します、わかりません、教えてください |
| 禁止・注意 | 危ない、やめてください、待ってください、触らないで |

「わかりません」「教えてください」を言えるようにすることは、
どんな語彙より優先度が高い。**言えないまま作業させないため。**

### 優先度3：直近のつまずきの再出題
カルテの直近3回のログに同じ語・文法が2回以上「できなかった」と記録されている場合、
角度を変えて再度テーマにする（例：語彙で出したなら次は会話文脈で出す）。

### 優先度4：ロードマップの次の単元
上のいずれにも該当しなければ、`curriculum/roadmap.md` の未実施の単元を順に進める。

## 1回あたりの分量

| 研修生の状況 | 語彙 | 文法 |
|---|---|---|
| 来日3ヶ月未満 | 5語 | 1項目 |
| N4学習中 | 7語 | 1〜2項目 |
| N3学習中 | 10語 | 2項目 |
| 試験1ヶ月前 | 10語 | 2項目＋既習の復習 |

多く出しすぎない。**1回で覚えられる量を超えると定着しない。**

## 現場スタッフからの相談を教材化するとき

「〇〇が通じなかった」という相談を受けたら、以下を確認してから教材にする。

1. **語彙の問題か、敬語の問題か、速さの問題か** を切り分ける
   - 語彙 → その語のカードを作る
   - 敬語 → 同じ内容の「丁寧形／普通形」対比カードを作る
   - 速さ → 教材ではなく、スタッフ側への「ゆっくり・短く区切る」提案を返す
2. **その語が現場で本当に必要か** を判断する。施設独自の略語・隠語は、
   教材にする前に「正式な言い方に統一できないか」を上長に提案する
3. 教材化したら `materials/` に置き、相談してきたスタッフにも共有できる形にする

3の「スタッフ側への提案」は教材ではないので、`reports/` ではなく回答文で直接返す。

## カリキュラムを作る・見直すとき

`references/curriculum-design.md` を読んでから作業する。
既存の `curriculum/roadmap.md` がある場合は、作り直さず**差分で更新**する。
研修生ごとに進度が違うのは正常なので、ロードマップは共通、
進度はカルテ側で管理する。

## やってはいけないこと

- 教材フォーマットを独自に作る（`kaigo-japanese-material` に従う）
- 研修生の理解度を「遅い」「悪い」など評価語で書く（事実で書く）
- 1回に3項目以上の新出文法を詰め込む
- カルテを読まずに教材を作る（誰向けか分からない教材は作らない）
- エスカレーション事由（CLAUDE.md 第4項）に触れた内容を自分で処理する
