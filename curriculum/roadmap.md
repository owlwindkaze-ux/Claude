# カリキュラム・ロードマップ

介護施設のインドネシア人実習生向け。**現場で使う頻度の高い順**に並べています。
設計思想は `.claude/skills/kenshusei-kyoiku/references/curriculum-design.md` を参照。

進度は研修生ごとに違うので、個人の進み具合は `trainees/` のカルテで管理します。
このロードマップは全員共通の「順番」だけを定めます。

---

## 第1層：安全（来日〜3ヶ月）

これが言えないまま単独で業務に入れない、という最低限。

| # | 単元 | 中心となる表現 | 状態 |
|---|---|---|---|
| 1-1 | 助けを求める | わかりません／教えてください／もう一度お願いします | |
| 1-2 | 報告の型 | 〜さんが〜です／報告します／確認します | |
| 1-3 | 危険を伝える | 危ないです／待ってください／呼んできます | |
| 1-4 | 体調変化の語彙 | 熱、痛い、気分が悪い、息、食べられない | |
| 1-5 | 急変・事故の語彙 | 転倒、誤嚥、出血、意識、呼吸 | |
| 1-6 | 禁止・注意 | 〜しないでください／触らないでください | |

**1-1を最初にやること。** 「わからない」と言えないまま頷く癖がつくと事故につながる。

## 第2層：日常業務（3ヶ月〜1年 / N4）

| # | 単元 | 中心となる表現 | 状態 |
|---|---|---|---|
| 2-1 | 食事介助の声かけ | 〜しましょうか／召し上がれますか／とろみ、刻み、むせる | |
| 2-2 | 排泄介助 | トイレ、おむつ、交換します、お手伝いします | |
| 2-3 | 入浴介助 | 湯加減、洗います、お背中流しますね | |
| 2-4 | 移乗・移動 | 立てますか、つかまってください、ゆっくり | |
| 2-5 | 口腔ケア | 義歯、うがい、口を開けてください | |
| 2-6 | 申し送りを聞く | 〜とのことです／〜だそうです（聞き取り中心） | |
| 2-7 | 時間・順序 | 〜てから、〜あとで、〜まえに | |
| 2-8 | 依頼・許可 | 〜してもいいですか／〜ていただけますか | |

2-6は**話す練習ではなく聞き取り練習**。話せるようになる前に、聞けるようにする。

| # | 単元 | 中心となる表現 | 状態 |

| 3-6 | 苦情・要望への一次対応 | 申し訳ありません／担当に確認します | |
