# 定期実行（AI社員の「出社時刻」）

スキルと職務定義だけでは、依頼されたときにしか動きません。
定期実行を設定して初めて「社員」になります。

## 設定方法

Claude に**そのまま話しかけるだけ**でスケジュールが作られます。
以下のプロンプトをコピーして送ってください（時刻は施設の都合に合わせて変更可）。

---

### ① 週次：教材作成（毎週月曜 9:00）

```
毎週月曜9時に、このリポジトリで研修生教育担当の業務を実行して。
trainees/ の全カルテを読んで、各研修生に必要な教材を作り、
materials/ に保存して、カルテの学習ログを更新して。
```

### ② 週次：進捗レポート（毎週金曜 16:00）

```
毎週金曜16時に、今週の週次レポートを作って reports/ に保存して。
reports/_template-weekly.md の形式に従うこと。
```

### ③ 月次：カリキュラム見直し（毎月末）

```
毎月最終金曜の16時に、その月の週次レポートを読んで月次レポートを作り、
curriculum/roadmap.md の見直しが必要か判断して提案して。
```

---

## 運用のコツ

**最初の1ヶ月は定期実行にしない。** 手動で10回ほど動かして、
出てくる教材とレポートの質を確認してから自動化してください。
精度が出ないまま自動化すると、誰も読まないファイルが溜まるだけになります。

**レポートは人間が必ず読む。** 週次レポートの「6. 上長に判断をお願いしたいこと」は、
AI社員が判断を止めた箇所です。ここを放置すると止まった作業が溜まります。

**カルテは人間が更新する欄がある。** 「現場からの申し送り」欄が空のままだと、
AI社員は現場で何が起きているか分かりません。ここが一番効きます。

## 動作確認

定期実行を待たずに試すには、チャットでこう言ってください。

```
今日の研修生教育担当の業務をやって
```

```
T-001 さんの今週の教材を作って
```

```
「とろみ」が現場で通じなかったので教材にして
```
