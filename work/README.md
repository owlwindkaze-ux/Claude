# 作業用ディレクトリ

介護システムのExcelから抜き出した申し送りが、ここに一時保存されます。

## 重要

- **このディレクトリの中身はGitに登録されません**（`.gitignore` 済み）
- 利用者名はマスクされていますが、健康情報が残っています。
  **そのまま実習生に送らないでください**
- 送信用の教材は `materials/` に作られます。送るのはそちらです
- 使い終わったファイルは削除して構いません

## 置き場所

介護システムから落としたExcelも、ここに置いてください。

```
work/
  介護記録_202608.xlsx      ← ここに置く（Gitには入らない）
  2026-08-19-申し送り.md    ← 抽出結果（作業用）
```
